ชุด skill เอกสารไทย

ให้ AI จัดไฟล์ Word ภาษาไทยให้ถูกหลัก และไม่ให้ Word ขึ้นบรรทัดใหม่กลางคำ ใช้ได้กับ Claude Code, claude.ai, Codex และ Antigravity

ก่อนและหลัง

10.9%ขึ้นบรรทัดกลางคำ เมื่อปล่อย Word ตัดเอง
0.2%หลัง wrap (ข้อความทดสอบ 10 ย่อหน้า × ความกว้าง 7 ขนาด)

ตัวเลข 0.2% วัดกับข้อความทดสอบที่คำเฉพาะอยู่ในพจนานุกรมแล้ว กับข้อความที่ตัวตัดคำไม่เคยเห็น ผิดขอบเขตคำราว 3.6% เมื่อมี khammoon และราว 7.1% เมื่อใช้พจนานุกรมอย่างเดียว การทดลองแรก 4 ย่อหน้าได้ 12.8% → 2.0%

ทำอะไรได้

  • fixจัดหน้าทั้งไฟล์: ฟอนต์ TH Sarabun New ขนาดอักษรไทย-อังกฤษเท่ากัน ติดป้ายภาษาไทย (เส้นหยักแดงหาย) แก้อักษรเพี้ยน หัวข้อไม่ค้างท้ายหน้า เลือกเลขไทยและกระจายแบบไทยได้
  • checkตรวจไฟล์ก่อนส่งหรือพิมพ์ โดยไม่แก้ไฟล์
  • wrap / unwrapตัดคำล่วงหน้าให้ Word ขึ้นบรรทัดเฉพาะระหว่างคำ และถอดกลับเมื่อจะแก้เนื้อหา
  • segmentดูผลตัดคำ ไว้ตรวจหรือเพิ่มคำเอง

สคริปต์ไม่เรียก AI หรือเครือข่ายใดๆ ทำงานกับไฟล์ในเครื่องเท่านั้น ต้องมี Python 3.10 ขึ้นไป กับ python-docx และ lxml (เสริม numpy สำหรับตัวตัดคำ khammoon)

คำสั่งที่ใช้บ่อย

ในแชทพูดได้เลย เช่น "จัดไฟล์ report.docx ให้ตัดคำไม่ขาดกลางคำ แล้วบันทึกเป็น report_v2.docx" ถ้าจะรันเอง ให้อยู่ในโฟลเดอร์ที่มีไฟล์ของคุณ แล้วเรียกสคริปต์ด้วยที่อยู่เต็ม

# ตรวจก่อน ไม่แก้ไฟล์
python "<โฟลเดอร์ skill>/scripts/thaidocx.py" check ไฟล์.docx
# จัดหน้า บันทึกเป็นไฟล์ใหม่
python "<โฟลเดอร์ skill>/scripts/thaidocx.py" fix ไฟล์.docx ไฟล์_v2.docx
# จัดหน้า + เลขไทย + กระจายแบบไทย + ตัดคำ (ขั้นสุดท้าย)
python "<โฟลเดอร์ skill>/scripts/thaidocx.py" fix ไฟล์.docx ไฟล์_v2.docx --thai-digits --distribute --wrap-words
# ถอด wrap ก่อนแก้เนื้อหาต่อ
python "<โฟลเดอร์ skill>/scripts/thaidocx.py" unwrap ไฟล์_v2.docx ไฟล์_แก้ต่อ.docx

ไฟล์ปลายทางต้องเป็นคนละไฟล์กับต้นทาง และคำสั่งจะไม่ทำงานถ้าไฟล์ยังเปิดอยู่ใน Word

หนังสือราชการ thai-official-letters

ร่างหนังสือราชการเป็นไฟล์ Word ที่ระยะ ตำแหน่ง ขนาดอักษรตรงแนวทางการพิมพ์ แล้วตรวจก่อนส่ง ทำได้ 11 ชนิด: บันทึกข้อความ, หนังสือภายนอก, หนังสือประทับตรา, คำสั่ง, ระเบียบ, ข้อบังคับ, ประกาศ, แถลงการณ์, ข่าว, หนังสือรับรอง, รายงานการประชุม

# ดูร่างตัวอย่าง
python "<โฟลเดอร์ skill>/scripts/thaigov.py" example memo memo.json
# สร้างไฟล์ Word จากร่าง
python "<โฟลเดอร์ skill>/scripts/thaigov.py" render memo.json memo.docx
# ตรวจไฟล์
python "<โฟลเดอร์ skill>/scripts/thaigov.py" check memo.docx

ต้องมี Python 3.10 ขึ้นไป กับ pip install python-docx lxml pydantic ติดตั้งผ่าน Claude Code plugin ได้พร้อม thai-docx หรือใช้ thai-official-letters.zip จาก Releases

ไม่แจกตราครุฑและตราหน่วยงาน ไฟล์ที่สร้างมีกรอบแทนตรา ต้องใส่ตราเอง ผู้ใช้ต้องออกเลขหนังสือและลงนามเอง ตรวจผลที่แสดงจริงใน Word for Mac (14 พ.ย. 2569) กับเอกสารตัวอย่าง 4 ชนิด (หนังสือภายนอก บันทึกข้อความ หนังสือประทับตรา คำสั่ง) โดยให้ Word แปลงเป็น PDF แล้วดูทีละหน้า อีก 7 ชนิดมีแต่เทสอัตโนมัติ ยังไม่ได้ตรวจด้วยตา ส่วน Word for Windows และ LibreOffice ยังไม่ได้ทดสอบ

ข้อแลกเปลี่ยนของ wrap

  1. ใช้เป็นขั้นสุดท้ายก่อนส่งหรือพิมพ์ ข้อความที่พิมพ์เพิ่มภายหลังจะไม่ได้ป้ายไทย ให้ unwrap ก่อนแก้ แล้ว wrap ใหม่ (fix กับไฟล์ที่ wrap แล้วจะถอดและใส่คืนให้เอง)
  2. ต้องซ่อนเส้นตรวจคำสะกด เพราะ Word จะมองคำไทยเป็นภาษาอังกฤษ (fix ทำให้อัตโนมัติ)
  3. ค้นคำเดียวใน Word เจอ แต่ค้นวลีที่ข้ามคำอาจไม่เจอ เพราะมีอักขระความกว้างศูนย์ (ZWSP) คั่น ข้อความที่คัดลอกออกไปจะติด ZWSP ไปด้วย
  4. ไม่ใช่ค่าเริ่มต้นของ fix ต้องสั่ง --wrap-words หรือใช้ wrap เอง
