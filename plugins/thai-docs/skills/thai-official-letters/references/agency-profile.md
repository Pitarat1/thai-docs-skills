# ไฟล์ตั้งค่าหน่วยงานและตรา

ไฟล์ตั้งค่า (`agency.json`) เก็บข้อมูลหน่วยงานที่ใช้ซ้ำทุกฉบับ และค่าการพิมพ์ที่หน่วยงานต้องการต่างจากค่าเริ่มต้น
ไม่มีไฟล์นี้ก็ใช้งานได้ (ช่องที่ไม่รู้คงเป็น `[ระบุ…]`)

## หาไฟล์จากที่ไหน

1. `--profile FILE` ที่ใส่ตอน `render` หรือ `check`
2. ถ้าไม่ใส่: `~/.thaidocs/agency.json` (โฟลเดอร์ `.thaidocs` ในโฟลเดอร์บ้านของผู้ใช้) ถ้ามี
3. ไม่มีทั้งสอง: ไม่เติมข้อมูลหน่วยงาน และใช้ค่าการพิมพ์เริ่มต้น

ใช้ไฟล์เดียวกันทั้งตอน `render` และ `check` (ทั้งร่างและ .docx) เพราะ `check ไฟล์.docx` เทียบขอบกระดาษและฟอนต์กับค่าในไฟล์นี้

## ตัวอย่าง

```json
{
  "agency": {
    "org": "กรมตัวอย่าง",
    "address": ["กรมตัวอย่าง", "ถนนตัวอย่าง กรุงเทพฯ ๑๐๐๐๐"],
    "department": "กองตัวอย่าง",
    "phone": "๐ ๒๐๐๐ ๐๐๐๐",
    "fax": "๐ ๒๐๐๐ ๐๐๐๑",
    "email": "saraban@example.com",
    "doc_no_prefix": "ตย ๐๐๐๑",
    "signer_name": "นายสมมติ ตัวอย่าง",
    "signer_position": ["ผู้อำนวยการกองตัวอย่าง"]
  },
  "layout": {
    "font": "TH SarabunPSK",
    "emblem_png": "~/.thaidocs/emblem.png",
    "unit_word": "หน่วยงาน",
    "stamp_notify_only": false
  }
}
```

ทั้ง `agency` และ `layout` ไม่บังคับ key ที่ไม่รู้จักหรือชนิดค่าผิดทำให้คำสั่งหยุดพร้อมข้อความไทย (exit code 2)
ค่าข้างบนเป็นหน่วยงานสมมติ ให้ผู้ใช้กรอกข้อมูลจริงของตนเอง อย่าเดา

## ส่วน `agency`

ใช้เติมเฉพาะช่องที่ร่างยังเป็นค่าเริ่มต้น ว่าง หรือ `[ระบุ…]` ค่าที่ร่างระบุเองไม่ถูกทับ

| key | ชนิด | เติมลงที่ |
|---|---|---|
| `org` | ข้อความ | `issuer` (ผู้ออกคำสั่ง ระเบียบ ข้อบังคับ ประกาศ แถลงการณ์ ข่าว และส่วนราชการที่ส่งหนังสือประทับตรา) |
| `address` | รายการข้อความ (หรือข้อความเดียว) | `agency` ของหนังสือภายนอกและหนังสือรับรอง (ชื่อส่วนราชการ + ที่ตั้ง บรรทัดละรายการ) |
| `department` | ข้อความ | `owner_unit` ของหนังสือภายนอก/หนังสือประทับตรา และ `department` ของบันทึกข้อความ (ต่อด้วย "โทร. …" เมื่อมี `phone`) |
| `phone` | ข้อความ | `phone` ของหนังสือภายนอก/หนังสือประทับตรา และท้าย `department` ของบันทึกข้อความ |
| `fax` | ข้อความ | `fax` ของหนังสือภายนอก/หนังสือประทับตรา |
| `email` | ข้อความ | `email` ของหนังสือภายนอก/หนังสือประทับตรา |
| `doc_no_prefix` | ข้อความ | ไม่เติมลงเอกสาร (เก็บไว้อ้างอิงตอนเขียนร่าง เลขที่หนังสือผู้ใช้ออกเอง) |
| `signer_name` | ข้อความ | `signer.name` ของทุกชนิดที่มีผู้ลงนาม (ไม่เติมผู้จดรายงานการประชุม) |
| `signer_position` | รายการข้อความ (หรือข้อความเดียว) | `signer.position` |

ผู้ลงนามในไฟล์ตั้งค่าเป็น "ผู้ลงนามปกติ" ถ้าฉบับนั้นมีผู้ลงนามอื่น ให้ใส่ `signer` ในร่าง

## ส่วน `layout`

key ที่รับรอง (ชื่อตรงกับค่าใน `layout-w2019.md`):

| key | ชนิด | ค่าเริ่มต้น | ความหมาย |
|---|---|---|---|
| `font` | ข้อความ | TH Sarabun New | ฟอนต์ทั้งเอกสาร (`--font` ตอน `render` มีผลเหนือค่านี้) |
| `body_pt` | ตัวเลข | 16 | ขนาดเนื้อความ (พอยท์) |
| `margin_left_cm` | ตัวเลข | 3.0 | ขอบซ้าย (ซม.) |
| `margin_right_cm` | ตัวเลข | 2.0 | ขอบขวา (ซม.) |
| `margin_top_cm` | ตัวเลข | 1.5 | ขอบบน (ซม.) |
| `margin_bottom_cm` | ตัวเลข | 2.0 | ขอบล่าง (ซม.) |
| `thai_numerals` | จริง/เท็จ | true | เลขไทย (`--arabic-digits` ปิดได้ทุกกรณี) |
| `unit_word` | ข้อความ | ส่วนราชการ | ป้ายบรรทัดแรกของบันทึกข้อความ เช่น "หน่วยงาน" |
| `omit_signature` | รายการรหัสชนิด | ว่าง | ชนิดที่ไม่พิมพ์ชื่อ/ตำแหน่งผู้ลงนาม เช่น `["memo"]` เมื่อหน่วยงานลงนามในระบบสารบรรณอิเล็กทรอนิกส์ (ตัวตรวจไม่ตรวจช่องผู้ลงนามของชนิดนั้น) |
| `page_number_fmt` | ข้อความ | `- {} -` | รูปเลขหน้า `{}` คือตำแหน่งเลข |
| `emblem_png` | ข้อความ (path) | ไม่มี | ไฟล์ตรา PNG/JPEG ใช้ `~` แทนโฟลเดอร์บ้านได้ |
| `stamp_notify_only` | จริง/เท็จ | false | หนังสือประทับตราใช้แจ้งเพื่อทราบเท่านั้น (เปิดแล้วตัวตรวจเตือน `STAMP_NOTIFY_ONLY` และ `STAMP_CONCLUSION`) |
| `highlight_placeholders` | จริง/เท็จ | true | ทำแถบเหลืองที่ `[ระบุ…]` ในไฟล์ |

ค่าอื่นของ `LayoutSpec` ตั้งได้เช่นกันแต่ไม่รับรองความเสถียร

## ตรา

ชุดนี้**ไม่แจกตราครุฑหรือตราหน่วยงานใด** ผู้ใช้ต้องมีไฟล์ตราของตนเอง (PNG หรือ JPEG) ลำดับการเลือกไฟล์ตรา:

1. `--emblem FILE` ตอน `render`
2. `emblem_png` ในส่วน `layout` ของไฟล์ตั้งค่า
3. `~/.thaidocs/emblem.png`
4. ไม่มีทั้งหมด: ใช้กรอบสี่เหลี่ยมแทนตรา และ `render` พิมพ์บรรทัด "ใช้กรอบแทนตรา ต้องใส่ตราจริงก่อนใช้งาน …"

ไฟล์ที่ระบุแต่ไม่พบ หรือไม่ใช่ PNG/JPEG ทำให้คำสั่งหยุดพร้อมข้อความไทย (exit code 2)
เมื่อใช้กรอบแทนตรา ตัวตรวจไฟล์ไม่เตือน `GARUDA` (กรอบนับเป็นภาพ) จึงต้องบอกผู้ใช้เองว่าต้องใส่ตราจริงใน Word
หรือระบุไฟล์ตราแล้ว `render --force` ใหม่ รายงานการประชุมไม่มีตรา
