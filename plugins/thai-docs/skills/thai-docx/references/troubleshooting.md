# แก้ปัญหาที่พบบ่อย

คำสั่งในตารางรันในโฟลเดอร์งานของผู้ใช้ เรียกสคริปต์ด้วย path เต็ม: `python "<โฟลเดอร์ skill>/scripts/thaidocx.py" <คำสั่ง> …`
(`<โฟลเดอร์ skill>` คือโฟลเดอร์ที่มีไฟล์ SKILL.md)

## เอกสาร Word

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| เส้นหยักแดงทั้งหน้า ช่องไฟยืด ตัดคำผิด | run ไม่มี `w:cs`/`w:lang bidi=th-TH` (`check` รายงาน `NO_CS` หรือ `NO_LANG`) | `fix` (ติดป้ายไทย + ซ่อนเส้นตรวจคำ) |
| ข้อความแตกบรรทัดกลางประโยคหลังเปลี่ยนฟอนต์ | มี `<w:br/>` ที่ใส่ด้วยมือ (`MANUAL_BREAK`) | `fix --remove-manual-breaks` |
| คำอังกฤษตัวเล็ก/ใหญ่ผิดขนาด | `sz` ≠ `szCs` (`SZ_MISMATCH`) | `fix` |
| อังกฤษเป็นฟอนต์อื่นทั้งที่ไทยเป็น TH Sarabun New | docDefaults/theme เป็นฟอนต์อื่น, run ไม่ได้ตั้ง ascii (`THEME_FONT`, `MULTI_FONT`) | `fix` (หรือ `fix --font "ชื่อฟอนต์"`) |
| ตั้ง "ทำซ้ำแถวหัวตาราง" แล้วไม่ขึ้นหน้าถัดไป | แถวยาวเกินหน้าถูกตั้ง `cantSplit` (ห้ามแยกแถว) | ใน Word: Table Properties → Row → ติ๊ก Allow row to break across pages เฉพาะแถวยาว |
| ค้นคำว่า "สระแก้ว" ไม่เจอ / วรรณยุกต์ลอย | อักษร Private Use (U+F70x) จากฟอนต์เก่า หรือ "ํ"+"า" แทน "ำ" (`BAD_CHARS`) | `fix` แล้วตรวจด้วยตา |
| หัวข้อค้างท้ายหน้า | ไม่มี keepNext | `fix` (หัวข้อที่ไม่ใช้สไตล์ Heading และไม่ขึ้นต้นด้วยเลขหลายระดับ ต้องตั้ง Keep with next เอง) |
| ช่องลงชื่อเบี้ยว/ล้นบรรทัด | จัดตำแหน่งด้วยช่องว่าง | ลบช่องว่างนำหน้า ตั้ง left indent ≈ 7 ซม. + จัดกึ่งกลาง + keepNext/keepLines (`layout-rules.md` ข้อ 3) |
| หัวข้อที่คัดลอกจากอีกไฟล์กลายเป็นตัวเอียง ฟอนต์ Calibri | สไตล์ Heading ชื่อเดียวกันแต่นิยามต่างไฟล์ | คัดลอกสไตล์ต้นทางมาเป็นชื่อใหม่แล้วเปลี่ยน pStyle (`layout-rules.md` ข้อ 5) แล้ว `fix` |
| ตัว β, μ ใหญ่ผิดขนาด | ฟอนต์ไทยไม่มีอักษรกรีก โปรแกรมดึงฟอนต์อื่นมาแทน | ตั้งฟอนต์ run นั้นเป็น Times New Roman หรือเขียน "Beta" |
| ตัวตรวจ schema ฟ้อง `w:hint="cs"` | Word เขียนค่านี้เอง (มีตั้งแต่ไฟล์ต้นฉบับ) | ไม่ต้องแก้ ไม่กระทบการเปิด/พิมพ์ |
| ระยะบรรทัดบางย่อหน้าไม่เป็นบรรทัดเดี่ยวหลัง `fix` | ย่อหน้านั้นตั้งระยะแบบ exact (ล็อกความสูง) `fix` คงไว้และบอกจำนวนในรายงาน | ถ้าต้องการเดี่ยวจริง ให้เปลี่ยนเป็น Single ใน Word เอง |
| ระยะก่อนย่อหน้า 6 pt ไม่ขึ้น | ไม่ได้ใส่ `--doc` หรือส่วนนั้นอยู่นอกขอบเขต (ส่วนหัว/ลงชื่อของหนังสือ ตาราง) | ใส่ `--doc ราชการ` หรือ `--doc รายงาน`; ถ้าหัวข้อไม่ถูกจับเป็นหัวข้อ ให้ใช้สไตล์ Heading หรือทำตัวหนา (หัวข้อขึ้นต้นเลขต้องหนาทั้งย่อหน้า) |
| เลขอารบิกยังเหลือหลัง `--thai-digits` | เป็นเลขที่คงไว้ตามกติกา (URL, DOI, HC3) หรืออยู่ใน field code | ตรวจด้วย `check --thai-digits`; ฟิลด์ (สารบัญ เลขหน้า) ให้ Update Field ใน Word |

## การตัดคำ (`wrap`)

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| คำไทยขาดกลางคำตอนขึ้นบรรทัดใหม่ | Word ตัดคำไทยด้วยพจนานุกรมของตัวเอง | `wrap` เป็นขั้นสุดท้าย (`wrap-words.md`) |
| หลัง `wrap` พิมพ์เพิ่มแล้วข้อความใหม่ขาดกลางคำ/ขึ้นเส้นหยัก | ข้อความที่พิมพ์ภายหลังไม่ได้ผ่านการตัดคำ | `unwrap` → แก้เนื้อหา → `wrap` ใหม่ (หรือ `fix` ซึ่งถอดและตัดคืนให้เอง) |
| ชื่อเฉพาะ/ศัพท์หน่วยงานถูกตัดผิด | คำไม่อยู่ในพจนานุกรม | ตรวจด้วย `segment "ข้อความ"` แล้วเพิ่มคำในไฟล์ (บรรทัดละคำ) ใช้ `--words FILE` หรือใส่ใน `~/.thaidocs/words.txt` |
| เตือน "ไม่พบ khammoon/numpy" | ไม่มี numpy หรือใช้ฉบับไม่รวม khammoon | `pip install numpy` (ฉบับ nokhammoon ใช้พจนานุกรมอย่างเดียวโดยตั้งใจ) |
| ค้นวลีใน Word ไม่เจอ / ข้อความที่คัดลอกออกไปมีอักขระล่องหน | มี ZWSP (U+200B) ระหว่างคำ | ค้นทีละคำ หรือ `unwrap` ก่อนคัดลอก |
| ข้อความใน content control (ช่องกรอกของแบบฟอร์ม) ไม่ถูกตัดคำ | ยังไม่รองรับ `w:sdt` แบบในบรรทัด | ข้อจำกัดที่รู้แล้ว ตรวจด้วยตา |

## คำสั่ง / สภาพแวดล้อม

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| "ไม่พบไลบรารีที่จำเป็น" | ไม่มี python-docx / lxml | `pip install python-docx lxml` |
| "ไฟล์ … ยังเปิดอยู่ใน Word (พบไฟล์ล็อก …)" | มีไฟล์ `~$ชื่อไฟล์` ข้างไฟล์ | ให้ผู้ใช้ปิดไฟล์ใน Word แล้วสั่งใหม่ (ถ้า Word ปิดแล้วแต่ไฟล์ล็อกค้าง ให้ผู้ใช้ลบเอง) |
| "ไฟล์ปลายทางต้องเป็นคนละไฟล์กับไฟล์ต้นทาง" | OUT ชี้ไฟล์เดียวกับ IN | ตั้งชื่อเวอร์ชันใหม่ เช่น `_v2.docx` |
| บันทึกไม่ได้บนโฟลเดอร์ที่ mount จากเครื่องอื่น/คลาวด์ (`Device or resource busy`) | ระบบไฟล์ไม่ยอม rename ทับ | ให้ OUT อยู่ในโฟลเดอร์ทำงานบนเครื่อง แล้วคัดลอกไปปลายทางภายหลัง |
| สคริปต์ Python ของเราเองพังแบบ circular import | ตั้งชื่อไฟล์ซ้ำโมดูลมาตรฐาน (เช่น `struct.py`) | อย่าตั้งชื่อซ้ำ stdlib และรันด้วย `python -I` |
