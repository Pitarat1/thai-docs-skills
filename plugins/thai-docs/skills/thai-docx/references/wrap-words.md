# ตัดคำไม่ให้ขาดกลางคำ (`wrap` / `unwrap` / `segment`)

Word ตัดบรรทัดภาษาไทยด้วยพจนานุกรมของตัวเอง ชื่อเฉพาะ คำทับศัพท์ และศัพท์หน่วยงานจึงขาดกลางคำบ่อย
`wrap` ตัดคำให้ล่วงหน้าแล้วบอก Word ว่าขึ้นบรรทัดได้เฉพาะระหว่างคำ

## ใช้อย่างไร

```bash
python "<โฟลเดอร์ skill>/scripts/thaidocx.py" wrap ไฟล์_v2.docx ไฟล์_v3.docx            # ตัดคำ
python "<โฟลเดอร์ skill>/scripts/thaidocx.py" fix ไฟล์.docx ไฟล์_v2.docx --wrap-words     # จัดหน้าแล้วตัดคำในคำสั่งเดียว
python "<โฟลเดอร์ skill>/scripts/thaidocx.py" unwrap ไฟล์_v3.docx ไฟล์_แก้ต่อ.docx        # ถอดก่อนแก้เนื้อหา
python "<โฟลเดอร์ skill>/scripts/thaidocx.py" segment "อำเภอวังน้ำเย็นจังหวัดสระแก้ว"     # ดูผลตัดคำ คำ|คำ|…
```

## ทำงานอย่างไร

ตัวตัดคำ: จุดตัดที่ทั้งสองตัวเห็นตรงกัน (intersection) ของ
- **newmm** (พจนานุกรม) บนพจนานุกรมรวม: คำทั่วไป ~62,000 คำ + ชื่อคน/นามสกุล/จังหวัด + ชื่ออำเภอ/ตำบล +
  คำเฉพาะทางราชการ/สาธารณสุข + คำของผู้ใช้
- **khammoon** (โมเดลขนาดเล็ก ใช้ numpy) ช่วยคำทับศัพท์ เช่น ชื่อยา ศัพท์เทคโนโลยี ที่ใส่พจนานุกรมให้ครบไม่ได้
  ถ้าไม่มี numpy หรือใช้ฉบับไม่รวม khammoon จะใช้พจนานุกรมอย่างเดียวและเตือนหนึ่งครั้ง

ช่องว่างและจุดเปลี่ยนระหว่างไทย/ไม่ใช่ไทยเป็นจุดตัดเสมอ ไม่ตัดหน้าเครื่องหมายวรรคตอนอย่าง `. , ) ”`
และไม่ตัดที่ช่องว่างแบบห้ามขึ้นบรรทัด (no-break space)

ในไฟล์ Word ต่อย่อหน้าที่มีอักษรไทย (ทุกส่วน: เนื้อหา ตาราง หัว/ท้ายกระดาษ เชิงอรรถ):
1. ลบ ZWSP เดิมทั้งหมด (สั่งซ้ำได้ผลเท่าเดิม)
2. ต่อข้อความทุก run เพื่อหาจุดตัดทั้งย่อหน้า (คำอาจคร่อมหลาย run)
3. แยก run ที่จุดตัดคำ โดยคงรูปแบบเดิม (ตัวหนา ขีดเส้นใต้ ยกกำลัง)
4. run ไทยไม่ติดป้ายภาษาไทย (`w:cs` ถูกลบ, `w:lang` เป็น en-US) และฟอนต์ ascii/hAnsi/cs เป็นฟอนต์เดียวกัน
   Word จึงไม่ใช้พจนานุกรมไทยของตัวเองตัดกลางคำ
5. ใส่ ZWSP (U+200B) ระหว่างคำไทยที่ติดกัน เป็นจุดที่ขึ้นบรรทัดได้
6. บันทึกเครื่องหมาย `thaidocs.wrapped=1` ใน custom property ของไฟล์ (`check` รายงาน `WRAPPED`)

ไม่แตะ: field code (`instrText`), ข้อความใน hyperlink ยังคลิกได้, run ที่ไม่มีอักษรไทย
กระจายแบบไทย (thaiDistribute) ยังทำงานกับ run ที่ไม่ติดป้ายไทย

`unwrap`: ลบ ZWSP คืน `w:cs` + `w:lang bidi=th-TH` ให้ run ไทย รวม run ติดกันที่รูปแบบเหมือนกัน และลบเครื่องหมาย

## ผลวัด (Word for Mac)

| วิธี | จุดขึ้นบรรทัดที่ขาดกลางคำ |
|---|---|
| ปล่อย Word ตัดเอง | 10.9% |
| หลัง `wrap` | 0.2% |

วัดด้วยข้อความทดสอบ 10 ย่อหน้า × ความกว้าง 7 ขนาด (การทดลองแรก 4 ย่อหน้า: 12.8% → 2.0%)
ตัวตัดคำกับข้อความที่ไม่เคยเห็น ผิดขอบเขตคำราว 3.6% เมื่อมี khammoon และราว 7.1% เมื่อใช้พจนานุกรมอย่างเดียว

**ตรวจแล้ว:** Word for Mac (วัดตัวเลขข้างบน) และ Word for Windows (ทีมผู้ใช้เปิดไฟล์จริง ตัดคำถูก
ไม่มีปัญหาเมื่อปิดเครื่องหมายจัดรูปแบบ) ยังไม่ได้ตรวจ LibreOffice — ถ้าผู้ใช้ใช้โปรแกรมอื่น
ให้แปลง PDF ดูผลก่อนส่ง (`preview.md`)

## ข้อแลกเปลี่ยน (บอกผู้ใช้ก่อนใช้)

- เป็น **ขั้นสุดท้ายก่อนส่ง/พิมพ์** ข้อความที่พิมพ์เพิ่มภายหลังไม่ได้ผ่านการตัดคำ → `unwrap` ก่อนแก้
  แล้ว `wrap` ใหม่ (`fix` กับไฟล์ที่ตัดคำแล้ว จะถอดก่อนแล้วตัดคืนให้อัตโนมัติ)
- ถ้า `fix` ตัดคำคืนให้ไฟล์ที่เคยตัดแล้ว และเคยใช้คำเพิ่มเอง ต้องส่ง `--words FILE` ซ้ำอีกครั้ง
  (หรือเก็บไว้ที่ `~/.thaidocs/words.txt`) ไม่เช่นนั้นจะตัดคำด้วยพจนานุกรมมาตรฐานเท่านั้น
- เส้นตรวจคำสะกดต้องซ่อน (`fix` ทำให้แล้ว) เพราะ Word มองคำไทยเป็นภาษาอังกฤษ
- ค้นหาคำเดียวใน Word เจอ แต่ค้นวลีที่ข้ามคำอาจไม่เจอเพราะมี ZWSP; ข้อความที่คัดลอกออกไปจะติด ZWSP ไปด้วย
- ไม่ใช่ค่าเริ่มต้นของ `fix` — ต้องสั่ง `--wrap-words` หรือ `wrap` เอง
- ถ้าเปิดปุ่มแสดงเครื่องหมายจัดรูปแบบ (¶) ใน Word for Windows จะเห็นกล่องเล็ก □ ระหว่างคำไทย
  คือ ZWSP ที่ใส่ไว้ ปิดปุ่ม ¶ (Ctrl+Shift+8) แล้วจะหายไป และไม่ติดไปตอนพิมพ์

ข้อจำกัดที่รู้แล้ว:
- ข้อความไทยใน content control แบบในบรรทัด (`w:sdt`) ยังไม่ถูกตัดคำ
- ความเร็วราว 0.1 วินาทีต่อย่อหน้ายาวเมื่อใช้ khammoon

## เพิ่มคำเอง

1. ตรวจผล: `python "<โฟลเดอร์ skill>/scripts/thaidocx.py" segment "ข้อความที่ถูกตัดผิด"`
2. เขียนคำที่ต้องการลงไฟล์ข้อความ UTF-8 บรรทัดละคำ (บรรทัดที่ขึ้นต้น `#` เป็นหมายเหตุ)
3. ใช้กับคำสั่ง: `--words คำของฉัน.txt` (ใส่ได้หลายครั้ง) กับ `wrap`, `fix --wrap-words`, `segment`
   หรือวางไว้ที่ `~/.thaidocs/words.txt` ให้ใช้ทุกครั้งโดยอัตโนมัติ
4. รัน `segment` อีกครั้งเพื่อยืนยัน คำที่อยู่ในพจนานุกรมจะไม่ถูกตัดกลางคำทันที (ใช้จุดตัดที่ทั้งพจนานุกรม
   และ khammoon เห็นตรงกัน จุดในคำที่พจนานุกรมไม่ตัดจึงไม่มีทางเป็นจุดตัด) khammoon มีผลเพียงว่า
   ขอบหน้า/หลังคำนั้นจะเป็นจุดขึ้นบรรทัดได้หรือไม่
