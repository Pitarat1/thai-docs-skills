# จัดหน้าเอกสาร Word ภาษาไทย (thai-docx)

## ใช้เมื่อไร

- สร้างไฟล์ .docx ภาษาไทยใหม่ (python-docx) หรือแก้ไฟล์เดิมของผู้ใช้/แม่แบบหน่วยงาน
- ผู้ใช้บ่นว่า ขึ้นเส้นหยักแดงทั้งหน้า ช่องไฟยืด ฟอนต์ไม่เหมือนกัน คำอังกฤษตัวเล็กกว่าไทย
  คำไทยขาดกลางคำตอนขึ้นบรรทัดใหม่ หัวข้อค้างท้ายหน้า ต้องการเลขไทยทั้งเล่ม
- ต้องการตรวจไฟล์ก่อนส่ง/พิมพ์ว่าจัดหน้าไทยถูกต้อง

## เตรียมเครื่อง

- Python 3.10 ขึ้นไป และไลบรารี: รันคำสั่ง `pip install python-docx lxml`
- ตัวตัดคำ khammoon (แม่นขึ้นกับคำทับศัพท์) ต้องมี `numpy`: `pip install numpy`
  ถ้าไม่มี คำสั่งยังทำงานด้วยพจนานุกรมอย่างเดียวและพิมพ์เตือนหนึ่งครั้ง
- รันคำสั่งในโฟลเดอร์งานของผู้ใช้ (ที่ไฟล์ .docx อยู่) และเรียกสคริปต์ด้วย path เต็ม
  `<โฟลเดอร์ skill>` คือโฟลเดอร์ที่มีไฟล์ SKILL.md นี้ อย่าย้ายไปรันในโฟลเดอร์ skill (ไฟล์ IN/OUT จะไปอยู่ผิดที่)
- ถ้าคำสั่งแจ้งว่าไม่พบไลบรารี ให้ติดตั้งตามข้อความที่แสดง แล้วรันใหม่

## ขั้นตอน

### ก. สร้างเอกสารใหม่ด้วย python-docx

เขียนเนื้อหาให้ครบก่อน แล้วเรียก `layout.finalize` ครั้งเดียวก่อนบันทึก:

```python
import sys
sys.path.insert(0, "<โฟลเดอร์ skill>/scripts")   # ให้ import thaidocs ได้
from docx import Document
from thaidocs import layout
from thaidocs.digits import apply_thai_digits

doc = Document()
doc.add_heading("บทที่ 1 บทนำ", level=1)
doc.add_paragraph("เนื้อความภาษาไทย ...")
layout.distribute(doc)          # (เลือก) กระจายแบบไทยให้ย่อหน้าเนื้อความ
apply_thai_digits(doc)          # (เลือก) เลขไทยทั้งเล่ม — ถามผู้ใช้ก่อน
layout.finalize(doc, font="TH Sarabun New", body_pt=16, doc_type="รายงาน")   # เรียกหลังสุดเสมอ; doc_type: "ราชการ" | "รายงาน" | ไม่ใส่
doc.save("ร่าง_v1.docx")
```

- อย่าเว้นวรรค/กด Shift+Enter เพื่อจัดตำแหน่ง ใช้การเยื้อง (`paragraph_format`) และการจัดแนวแทน
- จากนั้นทำต่อที่ข้อ ข. ขั้นที่ 2 (`check`) และขั้นที่ 4–5

### ข. แก้ไฟล์เดิมของผู้ใช้

1. **ไฟล์ต้องปิดอยู่**: ถ้ามีไฟล์ `~$ชื่อไฟล์` ข้างไฟล์ แปลว่ายังเปิดใน Word ให้ผู้ใช้ปิดก่อน
   (คำสั่งจะปฏิเสธเองถ้าพบไฟล์ล็อก) และทำงานบนสำเนาเสมอ ตั้งชื่อเวอร์ชันใหม่ เช่น `_v2`
2. **ตรวจ**: รันคำสั่ง `python "<โฟลเดอร์ skill>/scripts/thaidocx.py" check ไฟล์.docx` ดูรายการปัญหา
3. **จัดหน้า**: รันคำสั่ง `python "<โฟลเดอร์ skill>/scripts/thaidocx.py" fix ไฟล์.docx ไฟล์_v2.docx` เพิ่มตัวเลือกตามชนิดเอกสาร
   (`--thai-digits` สำหรับหนังสือราชการ/แบบฟอร์ม ก.พ. — ถามผู้ใช้ก่อน; `--distribute`; `--remove-manual-breaks`)
   และ `--doc ราชการ` หรือ `--doc รายงาน` ตามเนื้อหา (หนังสือ/บันทึกข้อความ = ราชการ; รายงาน วิจัย บทความที่มีหัวข้อ = รายงาน;
   ถ้าไม่แน่ใจให้ถามผู้ใช้ ถ้าไม่เข้าทั้งสองแบบไม่ต้องใส่) `fix` ตั้งระยะบรรทัดเดี่ยวให้ทุกกรณี
4. **ดูผล**: แปลงเป็น PDF แล้วเปิดดูทุกหน้า (วิธีใน `references/preview.md`) แล้ว `check` อีกครั้ง
5. **ตัดคำเป็นขั้นสุดท้าย** (ถ้าต้องการ): เมื่อเนื้อหานิ่งแล้วเท่านั้น
   รันคำสั่ง `python "<โฟลเดอร์ skill>/scripts/thaidocx.py" wrap ไฟล์_v2.docx ไฟล์_v3.docx` หรือใส่ `--wrap-words` ตอน `fix`
   อ่านข้อแลกเปลี่ยนใน `references/wrap-words.md` ก่อนใช้

## คำสั่ง

`python "<โฟลเดอร์ skill>/scripts/thaidocx.py" <คำสั่ง> ...` (ไฟล์ปลายทางต้องเป็นคนละไฟล์กับต้นทาง ไม่เขียนทับไฟล์เดิม)

| คำสั่ง | ทำอะไร |
|---|---|
| `fix IN OUT [ตัวเลือก]` | จัดหน้าทั้งไฟล์ตามหลัก 10 ข้อ (ฟอนต์ ขนาด ระยะบรรทัดเดี่ยว ป้ายไทย ทำทุกส่วนรวมหัว/ท้ายกระดาษ เชิงอรรถ; กระจายแบบไทยและ keepNext ทำเฉพาะเนื้อหาหลักรวมตาราง) |
| `check IN [--thai-digits]` | รายงานปัญหาโดยไม่แก้ไฟล์ คืน exit code 1 ถ้าพบปัญหา |
| `wrap IN OUT [--words FILE]` | ตัดคำไม่ให้ขาดกลางคำเมื่อขึ้นบรรทัดใหม่ |
| `unwrap IN OUT` | ถอดการตัดคำ คืนเป็นข้อความไทยปกติ (ทำก่อนแก้เนื้อหาต่อ) |
| `segment "ข้อความ" [--words FILE]` | พิมพ์ผลตัดคำ `คำ\|คำ\|…` ไว้ตรวจหรือเพิ่มคำเอง |

ตัวเลือกของ `fix`:

| ตัวเลือก | ความหมาย |
|---|---|
| `--font "TH Sarabun New"` | ฟอนต์ทั้งเอกสาร (ค่าเริ่มต้น TH Sarabun New) |
| `--body-pt 16` | ขนาดเนื้อความใน docDefaults (ค่าเริ่มต้น 16) |
| `--thai-digits` | แปลงเลขอารบิกเป็นเลขไทย (ถามผู้ใช้ก่อน) คงอัตโนมัติ: URL อีเมล DOI, รหัสที่ขึ้นต้นด้วยอักษรละติน (COVID-19, v2.0, HC3), ISO/IEC 27001, ICC(1); เลขข้อและเลขหน้าเป็นเลขไทยด้วย |
| `--distribute` | ตั้งกระจายแบบไทยให้ย่อหน้าเนื้อความ (ข้ามหัวข้อ สารบัญ คำบรรยายภาพ ย่อหน้าที่มี URL) |
| `--remove-manual-breaks` | ลบการขึ้นบรรทัดด้วยมือ (เก็บที่ใช้คั่นรายการ "- …") |
| `--doc ราชการ` | (รับ `official`) ย่อหน้าเนื้อความของหนังสือ (ตั้งแต่หลัง "เรียน" ถึง "จึงเรียนมาเพื่อ…" ไม่รวมส่วนหัวและส่วนลงชื่อ; บรรทัด อ้างถึง และ สิ่งที่ส่งมาด้วย พร้อมรายการเลขใต้ข้อนั้น ถือเป็นส่วนหัว ชิดใต้ "เรียน" ไม่เพิ่มระยะ) ได้ระยะก่อนย่อหน้า 6 pt |
| `--doc รายงาน` | (รับ `report`) หัวข้อทุกระดับก่อนย่อหน้า 6 pt เนื้อความ 0 pt (สไตล์ Heading/ส่วนที่/บทที่ เป็นหัวข้อเสมอ; ย่อหน้าขึ้นต้นเลข เช่น "1. …" "1.1 …" นับเป็นหัวข้อเมื่อเป็นตัวหนาทั้งย่อหน้าเท่านั้น รายการเลขไม่หนาถือเป็นเนื้อความ) |
| `--wrap-words` | ตัดคำเป็นขั้นสุดท้ายของ `fix` |
| `--words FILE` | ไฟล์คำเพิ่มเติม บรรทัดละคำ (ใส่ได้หลายครั้ง) |

ลำดับใน `fix`: แก้อักษรเพี้ยน → ฟอนต์เดียวทั้งเอกสาร (ลบ theme font) → `sz=szCs` → (เลือก) ลบ br มือ →
(เลือก) เลขไทย → (เลือก) กระจายแบบไทย → keepNext หัวข้อ → ระยะบรรทัดเดี่ยว → (เลือก `--doc`) ระยะก่อนย่อหน้า →
ค่าเริ่มต้นเอกสาร → ป้ายภาษาไทยทุก run + ซ่อนเส้นตรวจคำ → (เลือก) ตัดคำ
· `fix` บังคับบรรทัดเดี่ยว (`line=240`, `after=0`) ทั้ง docDefaults สไตล์ และทุกย่อหน้า ยกเว้นระยะแบบ exact ที่คงไว้และรายงานจำนวนให้
· ถ้าไฟล์ถูกตัดคำไว้แล้ว `fix` จะถอดก่อนแล้วตัดคืนให้เอง
  (ถ้าเคยใช้ `--words FILE` ต้องใส่ `--words` ซ้ำตอน `fix` อีกครั้ง หรือเก็บคำไว้ที่ `~/.thaidocs/words.txt`)
  · ข้อความ "N จุด/ย่อหน้า" ที่ `fix`/`wrap` พิมพ์นับเป็นจำนวนย่อหน้าที่ถูกแก้

รหัสที่ `check` รายงาน:

| รหัส | ความหมาย | แก้ด้วย |
|---|---|---|
| `NO_CS` | run ภาษาไทยไม่มีป้าย `w:cs` (เส้นหยักแดง ตัดคำผิด) | `fix` |
| `NO_LANG` | run ไทยมี `w:cs` แต่ไม่มี `w:lang bidi=th-TH` (Word ตรวจคำสะกดผิดภาษา) | `fix` |
| `SZ_MISMATCH` | `sz` ≠ `szCs` (อังกฤษ/ไทยขนาดไม่เท่ากัน) | `fix` |
| `THEME_FONT` | ฟอนต์อ้างอิง theme (theme ชนะฟอนต์ที่ตั้งตรง) | `fix` |
| `MULTI_FONT` | ใช้ฟอนต์มากกว่าหนึ่งชนิด | `fix --font …` |
| `MANUAL_BREAK` | ขึ้นบรรทัดด้วยมือ | `fix --remove-manual-breaks` |
| `BAD_CHARS` | อักษรไทยเพี้ยน (Private Use, นิคหิต+า) | `fix` แล้วตรวจด้วยตา |
| `ARABIC_DIGITS` | เหลือเลขอารบิก (เมื่อสั่ง `--thai-digits`) | `fix --thai-digits` |
| `WRAPPED` | ไฟล์ถูกตัดคำแล้ว (ข้อมูล ไม่ใช่ปัญหา) | `unwrap` ก่อนแก้เนื้อหา |
